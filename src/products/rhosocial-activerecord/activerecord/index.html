06 / 06 · Sync & Async

像读英语一样写代码。

无需 DSL，方法即语义。同步与异步同一套 API，for → async for，其余不变。

example.py 
# 读取 like English
user = User.query().where(User.c.username == 'Alice').one()

# 保存 like English
user.save()

# 删除 like English
user.delete()

# async — same API
await User.query().where(User.c.username == 'Alice').one()
await user.save()
await user.delete()

Field Proxy

字段不只是容器。

FieldProxy 描述符让字段带有自定义行为，而不改变字段的类型签名。

models.py 
class Product(ActiveRecord):
    price: Money = Field(..., proxy=MoneyProxy)
    #                        ^ FieldProxyDescriptor

# 3 个用法
p = Product(price=Money(usd=99))
p.price.value            # 读裸值
p.price.in_range(0, 100)  # 调代理扩展方法
