Named Connection

连接别名管理，多数据源切换。

Resolver

NamedConnectionResolver。

通过完全限定名解析 Python 可调用对象返回 ConnectionConfig。

named_connection_resolver.py
from rhosocial.activerecord.backend.named_connection import (
    NamedConnectionResolver
)

# 生命周期：create → load() → describe() → resolve()
resolver = NamedConnectionResolver('myapp.get_replica_config')
resolver.load()

# describe() — 返回元信息 + 脱敏配置预览
info = resolver.describe()
# {qualified_name, is_class, docstring, signature, parameters, config_preview}

# resolve() — 调用并返回 BaseConfig
config = resolver.resolve()  # 无参
config = resolver.resolve(user_params={'host': 'replica.db'})

# 链式调用
config = NamedConnectionResolver('myapp.get_config').load().resolve()
Validators

安全验证。

validators.py
from rhosocial.activerecord.backend.named_connection import (
    validate_connection_config,
    filter_sensitive_fields
)

# validate_connection_config() — resolve() 内部自动调用
# 校验返回值 isinstance(config, BaseConfig)
# 不满足则抛出 NamedConnectionInvalidReturnTypeError

# filter_sensitive_fields() — describe() 内部自动调用
# 脱敏字段：password / secret / token / api_key / private_key
safe_preview = filter_sensitive_fields({
    'host': 'db.example.com',
    'password': 'secret123'
})
# → {'host': 'db.example.com'}  password 已移除
Module Scan

模块扫描。

list_named_connections_in_module() 自动发现模块中所有可调用对象。

module_scan.py
from rhosocial.activerecord.backend.named_connection import (
    list_named_connections_in_module
)

# 发现模块中所有可调用对象（函数 + 可调用类实例）
connections = list_named_connections_in_module('myapp.db.connections')
for conn in connections:
    print(conn['name'], conn['signature'], conn['docstring'])
Convenience

一步解析。

resolve_convenience.py
from rhosocial.activerecord.backend.named_connection import (
    resolve_named_connection
)

# 一步解析：load + resolve
config = resolve_named_connection('myapp.get_replica_config')

# 带参数
config = resolve_named_connection(
    'myapp.get_config',
    user_params={'host': 'replica.db'}
)
