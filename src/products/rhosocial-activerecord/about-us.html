rhosocial 是一个专注于开发高质量 Python 开源工具的组织。我们的旗舰项目 rhosocial-activerecord 是一款重新设计的 Python ORM，以类型注解为起点，追求简洁、透明和可扩展的设计理念。

我们的使命

在 Python ORM 领域，开发者长期面临"魔法太多"和"配置过重"的困境。SQLAlchemy 功能强大但学习曲线陡峭，Django ORM 与框架深度耦合，Peewee 设计过时。我们相信 ORM 可以做得更好——用 Python 原生的方式，让类型注解同时成为模型定义、让链式查询透明生成 SQL、让同步与异步使用同一套 API。

核心价值

  • 类型优先（Type-First）——模型定义就是 Python 类型注解，无需额外 DSL 或配置
  • 透明可控（Transparent & Controllable）——每一条生成的 SQL 都可以通过 .to_sql() 审查，无隐藏行为
  • 同步与异步一致（Sync/Async Parity）——同一套 API，for 和 async for 的区别而已
  • 后端独立（Decoupled Backends）——ActiveRecord 层与 Backend 层松耦合，后端可独立使用
  • 零假设（Zero Assumptions）——无强制 Session、无强制迁移框架、无强制全局状态

技术栈

rhosocial-activerecord 以 Python 3.8+ 为目标，核心库纯 Python 实现，零 ORM 依赖（仅依赖 Pydantic v2 用于运行时类型验证）。支持六种数据库后端：SQLite、PostgreSQL、MySQL、MariaDB、SQL Server 和 Oracle，同步与异步双模式。

开源与社区

rhosocial-activerecord 以 Apache 2.0 许可开源。我们欢迎任何形式的贡献——无论是报告 bug、提交 PR、改进文档，还是提出功能建议。项目托管在 GitHub 上，由社区共同驱动发展。
